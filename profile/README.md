🚀 Quick Start (coming soon)

#### Install the MLabs CLI
npm install -g mlabs-cli

#### Initialize your project
mlabs init my-app

#### Connect to APIs (Auth, Workflows, Payments, etc.)
mlabs connect auth

// Example: authenticate a user
import { Auth } from "@mlabs/auth";

const auth = new Auth({ apiKey: process.env.MARCELLE_KEY });

const session = await auth.signIn("user@example.com", "password123");
console.log(session);
